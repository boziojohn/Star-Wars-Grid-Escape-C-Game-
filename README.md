# Star-Wars-Grid-Escape-C-Game-
A terminal-based strategy game written in C, where the player controls Princess Leia on a dynamically generated grid. The objective is to reach R2-D2 while avoiding obstacles, moving stormtroopers, and the pursuing Darth Vader. The game features multiple difficulty levels, randomized board generation, enemy AI movement, and special commands like hints, undo, and obstacle manipulation. Each level increases in challenge as the board shrinks, testing the player's decision-making and survival skills
